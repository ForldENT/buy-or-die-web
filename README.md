- PC 크롬·엣지·웨일 브라우저를 권장합니다.

## 게임 소개

내 PC 화면을 그대로 보는 시점의 트레이딩 게임입니다. 바탕화면 위에 HTS 창과 작업표시줄이 떠 있고, 시간은 현실보다 훨씬 빠르게 흐릅니다.

- **승리(BUY):** 총자산 10억 원 달성
- **파산(DIE):** 총자산 1만 원 미만

| 구분 | 내용 |
|---|---|
| 종목 | 국내 주식 50 · 해외 주식 50 · 코인 100, 실존 기업을 비튼 패러디 이름 |
| 시장 | 국내장 09:00~15:30, 해외장 22:30~05:00(한국 시간), 주말 휴장, 코인 24시간 |
| 거래 | 현물 매수·매도, 레버리지 롱·숏(청산가 있음) |
| 뉴스 | 하루 10개. 회사 악재는 몇 시간 안에 반드시 하락, 호재는 반드시 상승 |
| 이벤트 | 신규 상장·상장폐지, 드물게 대폭락장·대호황장 |
| AI | 유니티 내장 AI가 종목 이름·뉴스 제목·기사 본문을 만들고, 플레이할수록 스스로 학습 (오프라인, 무료) |

## 조작

| 키 | 기능 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `1` `2` `3` | 배속 1x · 2x · 5x |
| `↑` `↓` | 종목 이동 |
| `Tab` | 국내 / 해외 / 코인 탭 전환 |
| `N` | 뉴스 창 |
| `H` | 거래 내역 |
| `Esc` | 메뉴 |

## 패치 노트

### v1.2.2 — 2026-10-25
**튜토리얼 버그 수정**
- 튜토리얼 4단계 "종목 고르기"에서 코인을 골라도 다음 단계로 넘어가지 않던 문제를 고쳤습니다.
  - 마우스로 '코인' 탭을 누르면 키보드 `Tab` 키처럼 첫 코인이 바로 선택되고 다음 단계로 넘어갑니다.
  - 클릭하는 순간 마우스가 조금 움직이면 클릭이 스크롤로 처리돼 무시되던 문제를 고쳤습니다. 고해상도 모니터와 노트북 터치패드에서 특히 잘 생기던 문제입니다.
  - 주식을 고르면 "주식은 지금 장이 닫혀 있어요. 코인을 골라주세요"라고 안내합니다.

### v1.2.1 — 2026-10-25
**AI 신규 상장 · AI 뉴스 · 뉴스 창 (v1.2.0 내용 포함)**
- **신규 상장:**
  - 하루 평균 0.5개꼴로 새 주식·코인이 상장되고, 상장 예정과 상장 소식이 뉴스로 나옵니다.
  - 이름은 내장 AI가 실제 기업·코인을 비틀어 짓습니다.
  - 목록에 2일 동안 '신규' 배지가 붙습니다.
- **AI 뉴스 제목:** 템플릿을 그대로 쓰지 않고, 내장 AI가 매번 새 문장을 조합해 씁니다.
- **뉴스 창 (`N` 키 / 작업표시줄 '뉴스'):**
  - 목록과 기사 본문을 함께 봅니다.
  - 전체·보유·호재·악재·공시 필터가 있습니다.
  - 본문에 보도 당시 가격과 현재 가격이 나옵니다.
- **자기 학습:** 실제로 발표된 AI 뉴스 제목과 새 종목 이름을 학습 데이터에 저장하고, 다음 실행 때 다시 학습해 표현이 점점 다양해집니다. 설정 화면에서 학습한 개수를 볼 수 있습니다.
- **시세 변동 주기:** 시세가 2초에 한 번씩 바뀝니다. 설정에서 1·2·3초 중 고를 수 있고, 시계 아래 막대로 다음 변동까지 남은 시간이 보입니다.
- **튜토리얼:** 직접 해보는 단계는 조건을 채우면 자동으로 다음 단계로 넘어갑니다.
- **외부 AI 연결 제거:** 외부 서버나 API 키 없이 완전 오프라인으로 동작합니다.

### v1.1.0 — 2026-10-25 · 첫 웹 공개
**첫 공개 버전 (v1.0 기본 게임 + v1.1 업데이트)**
- **시작 화면:**
  - 회사 로고(ForldENT) → 게임 로고 인트로를 보여줍니다. 유니티 로고는 나오지 않습니다.
  - 타이틀에서 새 게임(튜토리얼 포함), 이어하기, 설정을 고를 수 있습니다.
- **시간 흐름:** 날짜와 시간이 흐르는 게 화면에 보입니다. 장 개장·마감과 주말 휴장이 있고, 매일 자정 자동 저장됩니다.
- **종목:** 국내 50 · 해외 50 · 코인 100개 패러디 종목이 있고, 관리종목 → 정리매매 → 상장폐지 단계가 있습니다.
- **뉴스:** 300종의 뉴스 중 매일 10개가 나오고, 뉴스 방향대로 몇 시간 안에 시세가 반드시 움직입니다.
- **거래:**
  - 현물 매수·매도와 레버리지 롱·숏(최대 배율, 청산가)이 있습니다.
  - 국내 주식은 상·하한가가 있습니다.
- **대폭락장 · 대호황장:** 낮은 확률로 시장 전체가 크게 출렁입니다.
- **거래 내역 저장:** 매수·매도 기록이 최대 1,000건까지 저장되고 `H` 키로 볼 수 있습니다.
- **배경 음악과 속도:** 잔잔한 배경 음악이 들어갔고, 게임 속도를 전체적으로 느리게 조정했습니다.
- **설정:** 효과음·배경음 볼륨, 상승 색(빨강/초록), 기본 배속, 알림, 자동 저장, 전체화면을 바꿀 수 있습니다.
